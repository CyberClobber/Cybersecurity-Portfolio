🏗️ 1. Laboratorio Local de Detección (SIEM, NIDS & Telemetría)

Entorno empresarial propio desplegado en entornos virtualizados (VMware) para la simulación de ataques, análisis de tráfico y centralización de logs.
* Infraestructura: Windows Server (Active Directory), Kali Linux, Wazuh SIEM, Suricata NIDS, Sysmon.
* Casos de Uso Documentados:
  * Caso 1: Reconocimiento local y ejecución de comandos sospechosos (whoami).
  * Caso 2: Enumeración y persistencia mediante inspección de Event ID 1 de Sysmon.
  * Caso 3: Ataque de fuerza bruta por RDP correlacionado en tiempo real (Nivel 10 en Wazuh).
  * Caso 4: Detección e inspección de tráfico de red malicioso mediante Suricata NIDS e integración con Wazuh.
  * Caso 5: Análisis de vulnerabilidades en aplicaciones web (Flask): simulación de exploit y aplicación de parches de seguridad.
